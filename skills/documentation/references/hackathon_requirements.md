# Hackathon documentation requirements (edit for your event)

A complete submission document is expected to cover:

- Clear project title and one-paragraph overview
- Problem statement and target users
- Proposed solution and key features
- Architecture / workflow
- Technology stack
- Implementation details
- Setup and usage instructions
- Security, privacy and data handling
- Testing / validation approach
- Limitations and future scope
- Team and submission details

Rules for reviewers reading the document:
- Every claim must be traceable to the submitted code/config.
- Missing information must be visible as a gap, never filled with guesses.
